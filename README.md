# Yltimate Client (starter)

A lightweight Fabric client-side mod starter for Minecraft Java 1.21.11.

## Included
- Compact Yltimate HUD
- FPS display
- Left-click CPS counter (currently does not work)
- WASD and mouse-button indicators
- Equipped armor-piece count


This is a starter mod, not a complete standalone launcher/client yet. It does not include Sodium-style renderer optimizations; those should be added as compatible performance mods or implemented separately.
